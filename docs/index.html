A question-and-answer assistant that tells HKU students and staff how to sort waste on campus — based exclusively on official HKU recycling documents, and every answer shows the exact source line it came from.

The problem

HKU's official recycling rules are scattered across the CEDARS and re‑Campaign websites and hall notices. Students often sort waste incorrectly, or only find out at the bin that their item isn't accepted there.

🧋

Unclear boundaries

Bubble-tea cups and takeaway containers have non-obvious sorting rules.

📋

Inconsistent lists

The materials accepted at each smart recycling point are not standardised.

🔋

Hazardous & bulky items

Batteries, appliances and furniture have special procedures students don't know.

The tool answers everyday sorting questions from HKU official documents only. It does not handle off-campus waste, fines, appeals, or disposal applications.

What we built

  • Curated HKU corpus (6 official sources, reviewed line-by-line)
  • Retrieval + citation pipeline (Flask · LlamaIndex · ChromaDB)
  • Deterministic router and validators (safety rules)
  • Refusal / deferral behaviour for hazardous & unsupported items
  • React chat interface

What we reuse

  • Text LLM via API (Qwen on Alibaba Cloud Model Studio)
  • Local embeddings (BAAI/bge-small-en-v1.5)
  • Frameworks: Flask, LlamaIndex, ChromaDB, React

A real answer

A genuine run of the pipeline. The answer is short, names the bin, and carries a verbatim excerpt with source, section and line numbers.

Does a Coke bottle go in the metal category?
No. Beverage plastic bottles go in the Plastic bin.
Citation
“Beverage plastic bottles” — Recycling 101: The Correct Choices poster, section Plastic > DOs, lines 31–31
Excerpts are copied by the server from the source text — the model never invents the quoted line.

When it refuses

The system is designed to fail safely. Here are real boundary and refusal behaviours, all from the test set.

REFUSE
“Where do I put an old phone charger?”
There is no campus-wide rule, so it refuses to name a bin and points the user to their hall tutor / CEDARS instead of guessing.
DEFER
“Where should I dispose of used batteries?”
Returns official guidance links and excerpts only — no operational disposal advice — and reminds the user to follow hall management rules.
DEFER
“My floor's sign says no plastic bottles here, but you said yes.”
On-site signs and staff always take priority. The system defers to the on-site instruction rather than overriding it.
REFUSE
“I'm in Causeway Bay — where can I throw this bottle?”
Out-of-campus disposal questions are refused; the tool is scoped to the HKU campus only.

Limitations

Photo input being validated

Photo input is implemented (it names the item, then retrieves and cites the bin); the image test set is not yet scored and the confidence threshold is still provisional.

Fixed corpus

Answers cover only the six official HKU sources saved on 18 Oct 2026, so recently changed rules may not be reflected.

Campus only

No off-campus disposal, no bin-distance comparison, no fines or appeals — those are out of scope by design.

Run it yourself

Live app: hku-recycling-helper.onrender.com (free hosting: after 15 idle minutes the first visit takes about a minute to wake up).

The core path runs locally in two commands. The README walks a non-programmer through setup, and the repository ships with cached demo answers so the walkthrough still works if the API key is unavailable.

1. pip install -r backend/requirements.txt  ·  python scripts/ingest.py

2. flask --app backend.app run --debug → open http://127.0.0.1:5000
